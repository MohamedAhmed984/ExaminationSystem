1. Reflection
It's a feature that allows a program to inspect its own types, methods, and properties at runtime, letting you examine or manipulate code dynamically while the application is running.

2. protected internal
A combination of protected and internal. It allows access to members from any class within the same project, as well as from derived/child classes even if they are located in external projects.

3. private protected
A combination of private and protected. It restricts access strictly to derived classes that are located within the same project/assembly, blocking external projects from accessing it even through inheritance.
